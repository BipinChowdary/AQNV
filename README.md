# AquaNavAI: Forecast-Aware Coastal ASV Mission Planning

This repository is the static GitHub Pages showcase for AquaNavAI, a research demonstrator for forecast-aware coastal autonomous surface vehicle mission planning. It summarizes the verified workflow, pinned NOAA-derived inputs, four route objectives, exploratory verification results, and research-only limitations.

The page contains the following sections: INFO, RESEARCH PROBLEM, SYSTEM WORKFLOW, COASTAL DATA AND INPUTS, ROUTE-PLANNING OBJECTIVES, NAVIGATION DEMONSTRATION, RESULTS AND VERIFICATION, LIMITATIONS, and PROJECT LINKS.

## Repository structure

- `index.html` - semantic showcase page
- `style.css` - DCGAN-reference glassmorphism styling
- `script.js` - neural background, theme toggle, video fallback, and scroll-to-top behavior
- `images/` - supplied research figures, interface still, recorded demonstration, font, and favicon
